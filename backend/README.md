# Starter backend PHP/MySQL

Import `database/schema.sql` via phpMyAdmin. Backend ini membutuhkan PHP 8.1+, PDO MySQL, HTTPS, dan environment `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`, `JWT_SECRET`. Tidak ada kredensial default. Jangan commit secrets. Ini starter scaffold, bukan backend produksi yang sudah diaudit; jangan hubungkan tindakan destruktif ke sistem eksternal tanpa API resmi dan otorisasi yang sah.
